# ExpenseIQ – Smart Expense Tracker

A responsive Expense Tracker web application built using **HTML, CSS, and JavaScript**.

## Live Demo

🌐 **[ExpenseIQ – Smart Expense Tracker](https://ajinkumar-project.github.io/expense-tracker-ajinkumar/)**

## GitHub Repository

💻 **[View Source Code](https://github.com/Ajinkumar-project/expense-tracker-ajinkumar)**

## Features

* Add income and expense transactions
* Enter amount, category, date, and description
* Edit and delete transactions
* View total income, total expenses, and current balance
* Filter transactions by income, expense, or category
* Store transaction data using browser Local Storage
* Responsive design for desktop and mobile screens
* Input validation and helpful error messages
* Monthly expense summary
* Category-wise expense chart

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Chart.js

## How to Run

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Ajinkumar-project/expense-tracker-ajinkumar.git
```

2. Navigate to the project directory:

```bash
cd expense-tracker-ajinkumar
```

3. Open `index.html` in a web browser.

No backend server or additional installation is required.

### Using GitHub Pages

The application is hosted using GitHub Pages and can be accessed directly from the Live Demo link above.

## Data Storage

The application uses the browser's **Local Storage** to save transaction data.

This allows transactions to remain available after refreshing or reopening the application in the same browser.

> Note: Clearing the browser's site data will remove the locally stored transactions.
